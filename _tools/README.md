# _tools

リポジトリのスキルを Claude Code のユーザースキルディレクトリへ導入するツール。

## install.sh

```
./_tools/install.sh [OPTIONS] [SKILL...]
```

リポジトリ直下のスキルを、インストール先ディレクトリへ symlink または実体コピーとして配置する。`SKILL...` を省略した場合は全スキルが対象となる。

### オプション

| オプション | 説明 |
| --- | --- |
| `--copy` | symlink ではなく実体をコピーする |
| `--force`, `-f` | インストール先に既存のファイルがあっても上書きする |
| `--dry-run`, `-n` | 変更を行わず、実行される操作を表示する |
| `--uninstall` | インストール済みのスキルを削除する |
| `--target DIR` | インストール先ディレクトリを指定する |
| `--list`, `-l` | インストール可能なスキルを一覧表示する |
| `--help`, `-h` | ヘルプを表示する |

### 環境変数

| 変数 | 説明 |
| --- | --- |
| `CLAUDE_SKILLS_DIR` | インストール先ディレクトリの既定値。未設定時は `~/.claude/skills` |

インストール先の決定順序は `--target`、`CLAUDE_SKILLS_DIR`、既定値。

### 削除

`--uninstall` は、インストール先がこのリポジトリ内を指す symlink である場合にのみ削除する。実体ディレクトリおよび他所を指す symlink は、`--force` を併用しない限り削除されない。

### 出力

各スキルに対し、以下のいずれかの行を出力する。

| 表記 | 意味 |
| --- | --- |
| `install` | 新規に配置した |
| `replace` | 既存を上書きして配置した |
| `remove` | 削除した |
| `ok` | 既に同一 symlink が存在するため何もしなかった |
| `skip` | 削除対象が存在しなかった |
| `warning` | 既存の非対象ファイルにより処理しなかった (標準エラー出力) |

末尾に、インストール先と処理件数・スキップ件数・失敗件数の要約を出力する。

### 終了ステータス

| 値 | 条件 |
| --- | --- |
| `0` | 失敗件数が 0 |
| `1` | 失敗件数が 1 以上、または引数が不正 |

### 使用例

```sh
# 全スキルをインストールする
./_tools/install.sh

# 対象を確認する
./_tools/install.sh --list
./_tools/install.sh --dry-run

# 特定のスキルのみを、既存を上書きしてインストールする
./_tools/install.sh --force code-comment-edit

# 別ディレクトリへ実体としてインストールする
./_tools/install.sh --copy --target ./dist/skills

# インストールを解除する
./_tools/install.sh --uninstall
```
